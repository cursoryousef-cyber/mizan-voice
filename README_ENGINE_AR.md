# ميزان صوت | محرك التقييم والتحليل الإحصائي v0.2

محرك مستقل لحساب مؤشرات الأداء ومصفوفة الالتباس (Confusion Matrix) بدقة وموضوعية.

## الميزات الجديدة في هذا الإصدار:
1. **التوافق التلقائي المباشر مع مختبر الملف الصوتي (`audio-upload-lab.html`):**
   - يقبل ملفات CSV المصدّرة مباشرة دون الحاجة لإعادة تسمية الأعمدة، حيث يتعرف بمرونة على `test_id` و `predicted_label` و `reference_label`.
2. **مجموعة الـ 30 سيناريو المرجعية الجاهزة (Benchmark):**
   - تم تضمين مجموعة البيانات المرجعية المراجعة بشرياً مسبقاً داخل المحرك؛ حيث يمكن للجنة التحكيم أو أي باحث الضغط على زر «تحميل مجموعة الـ 30 سيناريو المرجعية الجاهزة» لعرض المؤشرات ومصفوفة الالتباس فوراً.
3. **حساب متوسط WER:**
   - إذا تضمن ملف النتائج قياسات دقة التفريغ الصوتي (WER)، يقوم المحرك بحساب متوسط معدل الخطأ تلقائياً.
4. **تصدير تقرير JSON:**
   - إمكانية تصدير كافة المؤشرات والمصفوفة بملف JSON منظم.
