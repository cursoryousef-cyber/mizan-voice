# ميزان صوت | Mizan Voice — محرك التقييم v0.1

هذه إضافة أولى إلى النموذج الحالي، وليست استبدالًا له.

## الملفات
- `evaluation-results-template.csv`: قالب إدخال نتائج نظام مختبَر.
- `evaluation-engine.html`: صفحة مستقلة لحساب المؤشرات من ملف CSV، إذا تم نشرها على GitHub Pages.

## الأعمدة المطلوبة
`scenario_id`, `reference_label`, `system_label`

القالب يملأ `reference_label` بوسوم مسودة من مجموعة البداية، ويترك `system_label` فارغًا. راجع الوسوم المرجعية بشريًا قبل الاعتماد، ثم أدخل في `system_label` نتيجة النظام المختبَر فعلًا. لا تملأ النتائج بالتخمين.

## القيود
هذا المحرك لا يحلل الصوت، ولا يتصل بلعبة أو منصة، ولا يكتشف المخاطر تلقائيًا. يحسب مؤشرات التقييم من مخرجات فعلية يُدخلها المستخدم. الوسوم المرجعية مسودات وتحتاج إلى مراجعة. لا تستخدم تسجيلات أطفال أو بيانات شخصية.
