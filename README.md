# ميزان صوت | Mizan Voice

منصة بحثية تجريبية دفاعية لتقييم وفحص سلامة المحادثات الصوتية العربية في الألعاب والتطبيقات الرقمية، مع التركيز على حماية الطفل وفهم السياق واللهجات العربية (بما فيها اللهجة السعودية).

---

## 🌟 الميزات والمكونات المكتملة في المشروع

تتكون المنصة من مسار متكامل يبدأ من الصوت الخام وحتى التقرير الإحصائي النهائي:

1. **مختبر تحليل الملفات الصوتية (`audio-upload-lab.html`):**
   - معالجة وفك ترميز ملفات الصوت الشائعة محلياً داخل المتصفح (`WAV`, `MP3`, `M4A`, `AAC`, `OGG`, `WebM`, `FLAC`).
   - تحويل الإشارة تلقائياً إلى قناة أحادية (Mono) وإعادة أخذ العينات إلى 16,000 Hz.
   - خوارزمية كشف السكون وانخفاض الطاقة الصوتية (Silence Detection).
   - تفريغ الكلام العربي محلياً عبر نماذج **OpenAI Whisper** المفتوحة المكيّفة للويب (`Xenova/whisper-tiny` و `Xenova/whisper-small`) عبر مكتبة Transformers.js و WebAssembly.
   - مؤشر دقة التفريغ: حساب **Word Error Rate (WER)** بمقارنة النص المفرغ مع النص المرجعي الصحيح (Ground Truth)، مع خوارزمية **التطبيع العربي المتقدم** (إزالة التشكيل، توحيد الهمزات والألف والتاء المربوطة والياء).
   - الفرز الأولي المستقل: قواعد فحص مصنفة لا تعتمد على حجب الكلمات فقط، وتُظهر بوضوح أن عدم مطابقة الكلمات يعني «غير محسوم ويتطلب مراجعة بشرية».
   - سجل التقييم وتصدير CSV بتشفير UTF-8 مع علامة BOM (`\uFEFF`) ليفتح مباشرة في Microsoft Excel بأحرف عربية سليمة.

2. **محرك التقييم والتحليل الإحصائي (`evaluation-engine.html`):**
   - تحليل نتائج الاختبارات وحساب المؤشرات المعيارية:
     - **Accuracy** (التطابق متعدد الفئات).
     - **Precision** (الدقة الإيجابية للحالات الضارة).
     - **Recall** (الاستدعاء واكتشاف المخاطر).
     - **F1-Score** (المتوسط التوافقي).
     - **False Positive Rate (FPR)** (معدل الإنذارات الخاطئة).
     - **Average WER** (متوسط معدل خطأ الكلمات).
   - توليد **مصفوفة الالتباس (Confusion Matrix)** التفاعلية ثنائية ومتعددة الفئات.
   - إمكانية استيراد ملفات CSV المصدرة من المختبر مباشرة، أو تحميل **مجموعة الـ 30 سيناريو المرجعية الجاهزة** بضغطة زر.
   - تصدير التقرير النهائي بصيغة JSON.

3. **مختبر الميكروفون المباشر (`voice-lab-asr.html`):**
   - التقاط الكلام المباشر عبر واجهة `SpeechRecognition` المدمجة بالمتصفح، وتصنيفه ومقارنته.

4. **مختبر النطق والسيناريوهات (`voice-lab.html`):**
   - اختبار النصوص بقواعد الكلمات وتوليد الصوت الاصطناعي للاختبار.

5. **الصفحة الرئيسية للمنصة (`index.html`):**
   - لوحة تحكم تفاعلية توضح مسار عمل المنصة، وتوزيع السيناريوهات، والتغطية اللغوية، مع روابط سريعة لجميع المختبرات.

## 🔒 الخصوصية والأمان ومبدأ العمل المحلي

- **معالجة محلية 100%:** كافة عمليات قراءة الملفات الصوتية، وفك الترميز، وتحويل الكلام إلى نص، والتصنيف، وحساب المؤشرات تتم **محلياً داخل متصفح المستخدم** بواسطة Web Audio API و WebAssembly و ONNX Runtime Web.
- **لا رفع للتسجيلات:** لا يتم رفع أي ملف صوتي أو نص إلى أي خوادم خارجية تابعة لميزان صوت.
- **أوزان النماذج المفتوحة:** في أول تشغيل، يتم تنزيل أوزان نموذج Whisper المفتوحة من شبكة Hugging Face العامة لمرة واحدة وتُخزن محلياً في ذاكرة التخزين المؤقت للمتصفح.
- **نسخة تجريبية ودفاعية:** صُممت هذه المنصة كأداة بحثية لتقييم الأنظمة وليس كأداة مراقبة أو نظام عقوبات تلقائي ضد المستخدمين.

## 🧪 جناح الاختبارات الآلية والتحقق

يحتوي مجلد `test/` على مجموعة اختبارات مؤتمتة تم التحقق منها داخل بيئة متصفح Google Chrome:
- `test/unit-tests.test.cjs`: اختبارات الوحدة لحساب WER، التطبيع العربي، وقواعد التصنيف، وتنسيق CSV (نجاح 8 / 8).
- `test/comprehensive-browser-suite.cjs`: جناح اختبار المتصفح الشامل الذي يغطي 20 سيناريو حقيقي في واجهة المستخدم (نجاح 20 / 20).
- `test/e2e-transcription.cjs`: اختبار تكاملي End-to-End يختبر رفع ملف صوتي وتفريغه بنموذج Whisper واستخراج النص وحساب المؤشرات.
- `test/verify-live-production.cjs`: اختبار التحقق المباشر من النسخة المنشورة على GitHub Pages.

لتشغيل الاختبارات محلياً:
```bash
node test/unit-tests.test.cjs
node test/comprehensive-browser-suite.cjs
```
