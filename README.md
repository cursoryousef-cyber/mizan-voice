# ميزان صوت | Mizan Voice

**نموذج واجهة أولي تفاعلي** لمنصة تقييم سلامة المحادثات الصوتية العربية في الألعاب الرقمية.

## تشغيل النموذج محليًا

افتح `index.html` في متصفح حديث. لا يحتاج النموذج إلى تثبيت حزم أو إعداد خادم.

## محتويات المستودع

- `index.html`: واجهة النموذج الأولي التفاعلي.
- `Mizan_Voice_Starter_Test_Set_30.csv`: مجموعة أولية من 30 سيناريو وصفيًا لتطوير خطة الاختبار.

## الحالة والقيود

هذا إصدار أولي يركز على الواجهة وعرض سير العمل. لا يتصل بمحرك فعلي لتحليل الصوت أو بخدمة إشراف خارجية، ولا يرفع التسجيلات إلى الإنترنت. المؤشرات والقيم المعروضة في وضع المحاكاة توضيحية وليست نتائج قياس فعلية. وسوم مجموعة السيناريوهات مسودات أولية تتطلب مراجعة بشرية قبل اعتمادها كمرجع.

## الخصوصية والاستخدام المسؤول

تُفضَّل أصوات اصطناعية أو مشاركون بالغون بموافقة صريحة عند إنشاء عينات صوتية مستقبلًا. لا تستخدم تسجيلات أطفال حقيقية أو بيانات شخصية. يجب إجراء أي اختبار على نظام تملك الإذن باختباره، مع توثيق حدود العينة وأخطاء التفريغ وأخطاء التصنيف والإنذارات الكاذبة.

## النشر عبر GitHub Pages

من إعدادات المستودع في GitHub، افتح **Settings → Pages**، واختر النشر من الفرع `main` والمجلد `/(root)`، ثم احفظ الإعداد. بعد اكتمال النشر سيعرض GitHub رابط الموقع في صفحة Pages.
